# Knowledge Base

A markdown-based knowledge base of interconnected wiki pages. Each page
is atomic, densely linked, and structured with frontmatter, key points,
examples, and connections.

Built and maintained with the [wiki-kb](https://github.com/juanje/wiki-kb) skill.

## How to use

### Browse

Open this directory in [Obsidian](https://obsidian.md/) for graph
visualization and link navigation. Start from `index.md` for a
categorized overview or `tags.md` for thematic navigation.

### Query with an AI assistant

The `AGENTS.md` file (and `CLAUDE.md` symlink) configures AI assistants
to answer questions using **only** the wiki content. Open this directory
as a workspace in your assistant and start asking questions.

## Structure

- `index.md` — categorized navigation with page descriptions
- `glossary.md` — all glossary terms with definitions
- `tags.md` — thematic navigation by tag
- `<category>/` — pages grouped by topic
